## 1. Audit Classification Taxonomy

Every scientific and empirical claim in existing project documentation, reports, and previous manuscripts is audited and classified into one of the following six mutually exclusive categories:

| Code | Classification Category | Definition & Verification Requirement |
| :---: | :--- | :--- |
| **A** | **EXPERIMENTALLY VERIFIED** | The result is directly supported by actual experiment outputs, fully traceable to raw artifacts, and independently reproduced in this audit. |
| **B** | **MATHEMATICALLY DERIVED** | The statement follows from a rigorous mathematical derivation whose exact boundary conditions and assumptions were verified against the actual codebase. |
| **C** | **OBSERVED BUT NOT STATISTICALLY ESTABLISHED** | An empirical effect was measured in the sample, but statistical evidence (e.g., FWER Holm adjustment, sample size) does not support a general confirmatory conclusion. |
| **D** | **NOT TESTED** | The hypothesis or claim was never evaluated by any experiment in the repository. Must NOT be presented as a finding. |
| **E** | **CONTRADICTED** | Actual experimental or mathematical evidence contradicts the original claim. Requires explicit retraction or correction. |
| **F** | **UNVERIFIABLE** | Required source data, raw predictions, or provenance logs are missing or corrupted, preventing reproduction. |
